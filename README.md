# Specialty Pharmacy Clinical Documentation & Analytics Platform

A full stack clinical analytics platform built to address a 
workflow gap in specialty pharmacy patient management programs.

**Live Demo:** [lopezls-datacollector.streamlit.app](https://lopezls-datacollector.streamlit.app)  
**Analysis Report:** [View on GitHub Wiki](https://github.com/lopezls/DataCollector/wiki/Analysis)
**App Walkthrough:** [View on GitHub Wiki](https://github.com/lopezls/DataCollector/wiki/App-Walkthrough)

## Overview

Specialty pharmacy patient management programs generate thousands 
of clinical interactions annually that go undocumented at the 
aggregate level. This platform was independently designed and 
built to capture structured encounter data and surface real-time 
clinical insights that did not previously exist in a structured form.

## Features

- Clinical encounter data collection form
- Drug catalog with auto-categorization by therapeutic area
- Real-time analytics dashboard including:
  - KPI metrics and counseling rates
  - Drug utilization distribution
  - Adverse drug event reporting trends
  - Language distribution (English/Spanish/other)
  - Survey completion rates
- Raw data table with filtering and CSV export
- Published descriptive analytics report

---

## Tech Stack

- **Python** — core application logic
- **Streamlit** — web application framework
- **SQLite** — local database
- **Plotly** — interactive data visualizations
- **Pandas** — data manipulation

## Clinical Context

Built by a practicing Senior Specialty Consultative Pharmacist
